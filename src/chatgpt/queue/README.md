Queue (#630): one accumulating pending prompt per account + conversation.
`text.js` (how contributions combine), `store.js` (IndexedDB v2 schema, legacy row migration), `queue.js` (the engine: append/edit/delete, the atomic claim into an immutable in-flight snapshot, lease-fenced dispatch, Steer (native steer, else stop then send)), `dispatch.js` (single send/stop boundary and the dry-run adapter), `composer.js` (reading/writing the native composer), `controller.js`/`view.js` (the one-bubble card above the composer, the wake-ups and the native-composer Enter interception), `markers.js` (the sidebar pencil on conversations with a queue). `live-dispatcher.js` is the default transport (stages the text in the composer, clicks Send/Steer/Stop, after verifying the page's own conversation and that its turns have loaded; its waits run on `core/worker-timer.js` timers); `config.dryRun` swaps in `DryRunDispatcher`. Tests drive it against fixtures only.
